# 交付图片、文案、发布链接

同一组 **3:4 卡片** 可由用户手动发布到小红书、抖音图文、公众号小绿书。默认只生成图片和文案，不执行平台侧自动化。用户明确要求更新已有公众号草稿时，仅按 `wechat-project-footer.md` 的限定流程原位更新并校验，不新建或公开发布；下述禁区适用于未获此项明确授权的默认交付流程。

## 最终回复只给三件事
- 图片：`output/` 目录路径，并说明按文件名前缀 `00、01、02...` 上传。
- 文案：`copy.md` 文件路径。
- 发布链接：按平台给出入口 URL。

## 发布入口
- 小红书创作服务平台：https://creator.xiaohongshu.com/
- 抖音创作服务平台：https://creator.douyin.com/creator-micro/content/upload?default-tab=3
- 微信公众平台：https://mp.weixin.qq.com/

## 自动化禁区
- 不打开小红书、抖音、公众号后台的创作/发布页面。
- 不用浏览器自动化上传图片、填写标题、粘贴正文、选择话题或点击暂存。
- 不调用公众号 API 建草稿，不读取或使用 `wx-creds.env`。
- 不运行 `xhs-publish.mjs`、`douyin-publish.mjs`、`wechat_lvshu_draft.mjs` 之类的发布/建草稿脚本。
- 不复用平台登录态、Chrome profile 或扫码登录流程。

## 交付前检查
- 图片尺寸为 1080×1440，文件名从 `00` 开始连续编号，顺序正确。
- 通用图片与小红书/抖音文案不出现外部引流；小绿书文末按 `wechat-project-footer.md` 保留指定学习网站介绍文章与两个项目文章链接。
- 正文段不包含乱用引号：`/["“”‘’「」『』]/` 命中就重写。
- 小红书/小绿书正文有平台语感和自然收尾；抖音正文纯数字、无 emoji、无图标。
- 小红书/抖音候选标签 8–12 个；小绿书正文不附话题，末尾先放 `学习网站：` 及指定介绍文章，再放 `Agent项目：` 及两个项目链接。交付 `wechat-content.html`，三条都是原生公众号文章链接，不能把 Markdown 或纯 URL 当成插入完成；本地校验不代表平台已保存。
